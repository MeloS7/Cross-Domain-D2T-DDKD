# Cross-Domain Data-to-Text (D2T) DDKD Repository

This anonymous repository is provided solely for sharing data and code during the review period. The official (non-anonymous) version will be released publicly upon paper acceptance.

## Data
We provide the following resources:
- Human evaluation set and annotation results
- Model outputs and LLM-as-a-judge annotations
- QUINTD-1 training and test data
- QUINTD-5 training data

Since the data folder is too large, we provide the .zip file.

## Code
We provide the following code:
- LLM-as-a-judge evaluation via API
- Human–LLM agreement analysis
- Human–human agreement analysis (inter-annotator agreement; IAA)
- LLM–LLM agreement analysis
- Human annotation set construction
- Evaluation analyses (error analysis, length analysis, etc.)

## Scripts
Training and inference are based on the MS-Swift library. We include example scripts for running the experiments.
